# 公開する形状・公開しない形状

既存CADとCAD・表ZIPは **C08で新たに作図したブレーキ部**と、ゼロから作図した
**参考円盤・参考支持リング・モーター包絡・参考入力軸**だけを扱います。
Pico Assy全体の再配布、互換部品集、製作・通電・回転の指示ではありません。

部品ごとの決定は [`data/provenance.json`](../data/provenance.json) に記録します。
`source_part → public_part → method → basis` が抽出根拠です。
その元となる [`scripts/public_policy.py`](../scripts/public_policy.py) は、部品ファミリーと本数を
明示し、未知の部品名・余分な連番・重複を拒否します。ワイルドカードによる形状の包括コピーはしません。

## 許可する新規部品

ヨーク、分割磁極蓋、コイル押え、分割ライニング、個別押え、PEEKボビン、巻線包絡、
予圧ばね、絶縁部品、キャリア、支柱、分割ハブ、可動円盤、接線ばねとねじ板、
配線保持部などの、新規に作図した形状です。ねじ・ナット・軸受・止め輪は独自の簡略プリミティブで、
メーカーのCADや第三者fastenerライブラリーからの形状は含みません。
ねじ山・工具穴・軸受内部・止め輪の実形状を完全再現した製造図ではありません。

**キャリアとハブの例外的な入力を明記します。**
これらの形状自体は円筒・リング・箱などから新規作成され、原モーターのBREPを足し引きしていません。
ただし、C08の生成時に原モーターCADから読んだPCD30上の3穴の中心座標を使っています。
これは取付位置の名目情報であり、実モーターのねじ深さ・材質・軸受許容荷重・現物互換を保証しません。
原モーターの表面形状やモデルを抽出する許可にはなりません。

新しいFreeCAD Documentへ、許可された部品の**評価済みShapeだけ**を入れます。
原Document、原グループ、外部リンク、履歴、作成者情報、参照ファイルはコピーしません。
nativeは部品の形状・配置を編集できるスナップショットです。
寸法変更で全機構が追従する、完全なパラメトリック設計履歴とは表示しません。

## 除外するもの

元のwheel、LOAD_FRAME、モーター、キューブ、corner、原Assyの全leaf、およびそのBoolean改変を除外します。
金属材に変更したframe/cornerでも、原形状由来のままなので「自作」とは扱いません。
元cornerにだけ接続するねじ、自由ばね参照、電装予約、原nativeの構築用オブジェクトも除外します。
X/Yの原全機部品は抽出せず、参考三軸は公開Zモジュールの剛体複製です。

原Pico Assyの再配布許諾は **UNKNOWN** です。ユーザーの公開依頼や不在時の自律継続は、
第三者形状の再配布許諾ではありません。紹介元は
[imo Labの紹介ページ](https://note.com/imo_g/n/n2f91e0cca4ba) と
[有料配布ページ](https://booth.pm/ja/items/5992975) です。
これらの原CAD、図面、レンダー、メーカーPDF/STP、原フォントを配布物へ入れません。

## 参考形状は検査対象の実機ではない

参考円盤は外径116 mmの**単純リング**へ新規部品の接続穴を作図します。元のスポーク・リムはトレースしません。
参考支持枠は外径138／内径120 mmの単純リングです。Picoの枠・cornerの代用設計ではありません。
参考モーターは任意の円筒包絡で、カタログ品や元モーターの再現ではありません。

参考部材へ元C08の全機質量・慣性・適合・工具経路・起立性能の検査結果を転記しません。
これらに接続する接合カードには、参考部材を含むことと、C08の締付計算値をそのまま適用できないことを表示します。
分解表示や参考三軸表示は配置説明のみで、実組立経路、衝突なし、構造強度、磁場の実証ではありません。

`whole_fit = build_ready = physical_ready = false` を維持します。

## 補助の全体参考図

[`overview.html`](../overview.html) は、独立して作図した筐体・2枚の基板・電池と、
その支柱・簡略ねじなど72要素を追加表示する説明図です。
出所・仮寸法・位置・相手は [`data/overview-layout.json`](../data/overview-layout.json) に記録します。
この生成器は既存の公開データだけを読み、private CAD・元筐体・メーカー基板データを読みません。
追加要素は既存FCStd/STEP/CAD・表ZIPに含めず、全機CADの配布や実基板への適合を装いません。
詳細は [参考全体図の範囲](OVERVIEW.md) を参照してください。
