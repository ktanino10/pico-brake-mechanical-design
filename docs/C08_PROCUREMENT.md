## 手持ちと今回の条件

モーターは **Nidec 24H055M020を1台**、12極ケーブルも所有済みで、新規購入はそれぞれ0です。
申告値は **A：円径6mm / B：有効突き出し15mm / C：D面から反対の曲面まで4mm / D：D面の軸方向長5mm**。
Cは平面の幅ではありません。測定誤差・D面開始位置・取付ねじ/穴深さ・許容荷重・電気入力は別途確認事項です。
この資料のために同じ写真や寸法を再提出する必要はありません。

新規締結はM3が希望ですが、原C08にはM2/M2.5/M3/M4が混在します。
ICは実装済みモジュールを候補にし、手作業は配線・リード部品・2.54mmヘッダー等を想定します。
保護接地を引けない条件のため、PE必須機器の接地を省く提案はしません。

## 1軸から3軸へ増えるもの

CSVの3軸列は、**同じ現行部品を各軸に置いた場合の参考数量**です。三軸同時実装の適合保証ではありません。
例：ヨーク1→3、摩擦材3→9、接線ばね3→9、完成軸受1→3。
所有motor/ケーブルは1台/1本なので、同型を3組使うなら追加2組が必要ですが、適合未確認のまま購入しません。

PC/Pico検討用セット、計測電源、ノギス/温度計/フォースゲージ、作業工具は**1軸ずつ試すなら共用**です。
電源を3台・計測器を3台と機械的に増やしません。巻線原材料は軸数で使用量が増えても、ロール/袋の購入数は別です。
レベル変換・5V電源・WAGO・ヒューズ・共通遮断の3軸数量は電源/回路設計後なので空欄です。
三軸機体のバッテリー・IMU・全体FW/配線・完成筐体は今回の1軸表に含めません。

| 拘束・防護・回転試験 | 静止試験用の反力受け/捕捉・計測レンジ/遮断が未設計。実ホイール・慣性/回転強度・保持が決まるまで低速でも回転承認しない |
| motor信号/制御 | 実入力電圧・Enable/PFM・停止/電源復帰の確認が必要。電源回復/ブレーキ解除後に勝手に再始動しない制御は未実装/未検証 |

この資料の完了は「必要品と不足条件を把握できる」状態です。加工品が製作承認された状態ではありません。
`whole_fit / build_ready / physical_ready = false`を維持します。
