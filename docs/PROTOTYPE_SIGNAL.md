# 履歴: 卓上R1の信号・電源設計 v1

**用途訂正: 以下は用途違いの卓上ソレノイド案の記録であり、3軸C08ブレーキの採用回路ではありません。**
先に訂正した電流制限条件・配線条件・未実装の自動始動防止要求は保持しますが、
この回路をC08のリング状巻線へ転用する設計/検証はしていません。[用途訂正の入口](../PROTOTYPE.md)。

**使う部品・GPIO・抵抗値を決めた接続設計です。24H055M020個体の入力適合を実測した結果ではありません。**
モーターへ接続する前に、下段の入力条件を確認します。任意の電圧を上げて未知の許容値を探す手順はありません。
機械側の[試験目標](PROTOTYPE_MECHANICAL.md)と合わせ、通電・購入・自動運転はこの資料作成中に行っていません。

## 3.3V、5V、12Vの分離

PicoはPCのmicro-B USBから給電。LVCのVAとセンサはPico3.3Vです。
モーター分岐ヒューズ後の12VをMPM3610へ入力し、その5VでLVCのVBとEnableリレーを給電します。
MPM3610の5V出力に1kΩ/0.25Wの放電抵抗を設けます（5mA、0.025Wの計算）。
ENはメーカー標準の有効状態、切替は上流の負荷電源。入力上限21VなのでDP100を30Vに設定しません。

GNDは基準として共通ですが、12V電流は端子台へ戻し、Picoやブレッドボードを通しません。
DP100 USB-Aは不使用。VBUS/VSYS/3V3/GPIOへ12Vを入れず、外部5VをVBUSへ逆給電しません。
装置全体が絶縁される構成ではなく、リレーだけでUSBの誤配線被害を防げるわけでもありません。
接地が必要な電源・測定器のPEを外す代用はしません。

**同じPH3極でもリレーV+は5V、MOSFET V+は12Vです。** ケーブルの交換を防ぐラベルと固定が必要です。
リレー基板の動作電流は約50mA。Pico側3.3Vと各電源の総電流も確認します。

## LVC・抵抗・接点

秋月[公式回路図](https://akizukidenshi.com/goodsaffix/AE-LLCNV-LVC8T245_sch_20210113.pdf)の
DIR/OEはそれぞれ出荷時10kΩでVAへプルアップ済み。小型抵抗の付け替えはしません。

1. DIRはHIGHのままA→B。OEをGP18へ接続し、起動時HIGH。
2. A1をGP20、A1→GNDに10kΩ。B1→GNDに10kΩ、B1から470Ω直列を経由してPFM出力候補へ。
3. A2〜A8はGND固定、B2〜B8には各10kΩ→GND。ほかへ接続しない。
4. リレーSignalとMOSFET Inにもそれぞれ10kΩ→GND。
5. センサOUT→1kΩ→GP26、GP26側に1nF→信号GND。

10kΩ/1%/0.25Wは合計11本、470Ω/0.25Wが1本、1kΩ/0.5Wが1本、
1kΩ/0.25Wが2本、1nF/50Vリードコンデンサが1個です。
TIのIoff/無給電時ハイインピーダンスにも条件があります。0〜5.5Vの範囲を超える12V耐性を作るものではなく、
470Ωだけで12Vを受けられるとも考えません。

| リレー接点 | 接続設計 |
|---|---|
| COM | モーターEnable候補 |
| NC | GND |
| NO | 1kΩ/0.5Wを介して負荷12V |

無励磁でEnableをGND側へ、励磁時だけ12V系へ切り替える設計です。
**1kΩ抵抗が正常に直列に入ったまま、12V側へ切り替わっているEnable出力がGNDへ短絡した場合**の定常計算は、
`I=12V/1kΩ=12mA`、抵抗の消費電力`P=12²/1000=0.144W`です。
抵抗自体が短絡・バイパスされた場合はこの電流制限が失われ、上記の数値は適用できません。
通常動作でも入力電流に応じてEnable電圧は下がります。
必要HIGHを満たさない場合は勝手に抵抗を短絡せず入力条件から見直します。接点移動中の開放状態も確認します。

ADA-4409の接点端子の適合線径は[メーカー指定で24〜18AWG](https://learn.adafruit.com/adafruit-stemma-non-latching-mini-relay/pinouts)です。
細いモーター付属リードをそのまま挟めるとは限りません。接点側には**0.5mm²（約20AWG）の中継線**を使い、
細いモーター線との接合部をはんだ付け・絶縁・引張り止めします。GPIO側の2.54mmジャンパー配線とは分けます。
方向はGND固定の1方向のみ。白線開放が内蔵ブレーキ解放となることは、当該個体で確認が必要です。
未確認5〜8番参照線は個別絶縁し、色順をメーカー番号として決めつけません。

## 回転記録・停止順序

センサは3.3V、暗いほど出力が高くなるアナログ方式です。
初期距離2mm、調整1〜5mm。白黒差0.5V以上を設計上の受入れ目標にし、静止値からしきい値/ヒステリシスを決めます。
非摩擦面の黒12/白12から黒への遷移だけを数え、12周期/回転。両エッジを数える24と混同しません。
2kS/sが設計目標で、300rpmなら60周期/秒、半周期約16サンプル。実間隔と欠測を確認します。
安全認証済みの過回転検出ではありません。

**制御の要求仕様（未実装・未検証）**として、開始・負荷電源復帰後の再開始は明示操作を必須にします。
停止の要求はEnable無効・PFM停止/OE無効→初期50ms待機→摩擦ブレーキ最長1秒→OFFです。
50msは実応答で検証/調整する値です。惰性比較では摩擦段階だけを省き、内蔵ブレーキ解放を両条件で維持します。
電源断は即時停止ではなく、外付けブレーキも解放され得ます。正常終了はSTOP、負荷電源OFF、最後にUSBを外す順です。

残る事実は、ハーネス極性/端子対応、5V PFM・12V系Enable・方向GND・白線解放の適合、
低速始動/停止・電源断波形・光学検出です。追加円板付きの高周波始動キックは採用しません。
実装済みモジュールの選定を元に戻すことではなく、選んだ回路が実物の入力条件を満たすかを確認します。
