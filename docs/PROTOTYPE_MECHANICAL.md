**用途訂正: この独立軸・対向レバー案は、3軸姿勢制御用C08の採用機構ではありません。**
以下の設計値・加工ファイル・検査は旧卓上R1の記録です。3軸用への適合・購入・製作を承認しません。
本来の構造は[公開C08](PUBLIC_SCOPE.md)、経緯は[用途訂正の入口](../PROTOTYPE.md)を参照してください。

**独立6mm軸を2個の626ZZで支え、60mmの金属円板を2枚のパッドで挟む構成に決めました。**
設計者が選べる寸法・数量は以下で固定します。実測していない材料性能やモーター定格とは区別します。
これは加工・印刷に使える**名目試作案**であり、実機の合格・安全速度・生産用承認ではありません。
既存C08と手回し教材は変更せず、モーター軸の穴あけやコントローラー取り外しもしません。

モーター本体のCAD表示φ55×65は**配置確認用の仮包絡**です。型番から実寸と認定していません。
V受けは40〜65mmの静止した円筒金属部を想定し、X方向の溝とM3ジャッキ4本で調整します。
1mmゴムを敷き、幅12mm・長さ300mmの面ファスナーベルト2本で保持。
黒い制御部や回転部を挟まず、静止金属面に幅6mmの受け2本を配置できることだけを現物で確認します。
ねじ孔PCDやねじ深さを測ってからブラケットを作る必要は、この保持方式ではなくなります。

軸寸法は申告済みのA6/B15/C4/D5を使用。Cは平面幅ではなく平面から反対曲面まで。
継手の挿入は8.5mmに固定し、D平面をクランプのスリット/座ぐり穴から避けます。
公差・平面開始位置・保持の実確認は必要ですが、軸径など4値を再質問する前提ではありません。

## 3. レバー・力・熱の見積もり

ソレノイド本体を片側レバー、プランジャーを反対側へ結び、2本の腕を引き寄せると下側のパッドが閉じます。
水平面内の開閉にした理由は、約60gのソレノイド自重で片側だけが閉じるモーメントを避けるためです。
両面の荷重は完全に等しいと保証せず、同じ隙間と静止荷重の確認で合わせます。

CA0830公式曲線の**3W連続**線は、冷間のストローク1mmでおよそ3N、2mmでおよそ2Nの読取りです。
グラフはDC24V/20°Cの系列データで、12V48Ω個体の保証曲線ではありません。
そこでR1は開放ストローク1.5mm、最小残り0.3mm、力の受入れ目標を**全使用域で1.5N以上**に決めます。
不足した場合はこの構成で合格とせず、電流や速度を上げずにソレノイド/リンクを再選定します。

名目レバー角0〜0.8°の幾何計算ではソレノイドストローク1.5〜約0.392mm。
左右の開放ストッパをM3×25、閉方向をM3×20で調整し、底突き前に止めます。
Φ2.8の滑らかなピンを、ソレノイドのφ3リンク穴と1.5mm板リンクへ通します。
2.1mmのフォーク隙間にM3ねじ山を押し込む設計ではありません。ピンは頭と割り止め線で抜け止めします。

ばねは初期圧縮3.5mmで約0.455N。動作時も約4.1mm圧縮以内、入力換算は約0.27Nです。
摩擦・リンク損失に0.4Nを見込み、`(1.5 − 0.27 − 0.4) × 2 ≈ 1.66N/面`が仮定上の下側見積もり。
受入れ目標は各面1.5N以上。設計だけで実荷重が出たとは扱いません。
ばねの全たわみ15.9mmに対して22〜26%で使用する計画です。

`T = Σ(μ_i N_i r_i)`。動摩擦係数を**仮に0.2**、各面1.5N、半径24mmなら0.0144N·m。
半径19mmを使う保守的計算は0.0114N·mです。KGR-1100はパッキン/防振材で、メーカー認定のブレーキ材ではありません。
低エネルギーの比較実験に限定し、剥離・引きずり・摩擦の低下があれば採用を中止します。
ゴム・金属用の接着剤を乾燥硬化させて静止パッドだけを固定し、印刷ポケットで横ずれを抑えます。
回転ハブや円板を接着剤だけで固定しません。

| 計算項目 | 結果と意味 |
|---|---|
| 円板質量 | 密度7930kg/m³仮定で約21.13g |
| 円板だけの慣性 | 約1.004×10⁻⁵kg·m²。6穴と中心穴を含む |
| 円板だけのエネルギー | 150rpmで約0.00124J、300rpmで約0.00495J |
| 追加回転部の設計慣性枠 | 4×10⁻⁵kg·m²。継手・ハブ・ねじ・軸も含めて実重量で照合する枠 |
| 全回転系のエネルギー枠 | 300rpmで0.1J以下をR1の設計制約とする |
| 未判明のモーター回転部 | 慣性を0で置かない。上記枠に入るには約1.63×10⁻⁴kg·m²以下の余裕しかない |
| 停止時間近似 | `T≈Iω/t`。全系が0.1J枠、300rpm、0.0114N·mなら減速部分約0.56秒。実応答遅延は別 |
| 円板平均温度上昇 | 比熱500J/kgKを仮定し0.1J全部を円板に入れても約0.0095°C。局所温度の証明ではない |
| パッド面圧 | 1.5N/80mm²で約0.0188MPa |

少量の停止エネルギーなので、低温部のPLA保持具を検討する合理性があります。
ただし連続摩擦・ソレノイドの局所発熱・接着・層間強度はこの平均温度計算では確認できません。
PLA/パッド40°C、ソレノイドケース45°Cで中止する設計目標を設定し、実温度と繰返しを記録します。

内部の回転部慣性が入手できない場合は、**モーター全体質量Mと、軸中心から外形までの最大半径R**を使って
`I_motor ≤ M R²`と保守的に上限評価できます。上限回転数は
`min(300, 60/(2π) × sqrt(2×0.1 / (4×10⁻⁵ + M R²)))` [rpm] とし、150rpm未満ならR1の初回回転を見送ります。
例えば全体300g・最大半径50mmなら150rpmで約0.0975Jですが、これは**例であって所有品の測定値ではありません**。
モーターを分解して慣性を測ることや、未知を0として扱うことは不要です。300rpmまで進めるかはこの上限でも制限します。

DXFはmm指定です。図や画面を目測して穴位置を拾わず、加工先へ図面・材料・公差を渡します。

1. STL17個を各1個。PLA、層0.2mm、外周6、上下6層、充填40%を初期条件とする。薄い支点や穴付近の欠損品は使わない。軸受台は穴のサポート除去後に仕上げる。
2. 先に軸受台1個でφ19.05の印刷穴を確認する。軸受を指で装着でき、外輪が空転しないこと。無理な打込みをせず、プリンター補正または穴仕上げで合わせる。
3. 台座へ軸受台2個を仮固定し、軸を通して平行を合わせる。内輪シムとカラーを取り付け、軸方向遊び0.10〜0.20mmを目標にする。外輪押えの0.1mm逃げをつぶさない。
4. ハブと円板をM3×6の6本で対角に均等固定。手回しで軸方向TIR0.10mm以下・径方向0.15mm以下、ねじ先と静止物の離隔を確認する。
5. V受けを静止金属部へ合わせ、ベルト2本とジャッキのダブルナットで保持。継手を片側8.5mm挿入し、軸が突き当たらないことを確認する。モーター本体は加工しない。
6. 支点台・ブッシュ・レバー・橋を組み、ソレノイドをクランプで保持。戻しばねをφ2.5ガイドへ通し、ピンを抜け止めする。クランプの取付はケースが動かず、PLAをつぶさない範囲。
7. パッドを所定位置へ固定し、中心隙間各0.15mmをすきまゲージで合わせる。閉側ストッパは片腕0.8°以内、ソレノイド残りストローク0.3mm以上となる位置でロックする。
8. [12周期マーク](../prototype/mechanical/sensor-track.svg)を100%で1枚印刷し、白い薄いPETラベルの連続円環として半径13.5〜18.5に固定。部分的なテープ重ねでアンバランスを作らない。
9. センサ基板は穴を使わずポケットと非導電ストラップで保持。ヘッダを外側へ向け、最初の距離2mm、調整1〜5mm。白黒差0.5V目標を満たす位置へ基板を調整する。
10. カバー5枚とアングル12個を組み、机へ固定。手回しで全周の非接触と配線保持を確認する。カバーを外した組立図は説明用で、試験状態ではない。

M3ハブねじやピンなど回転近傍の金属締結は、緩みをマーキングして各試験前後に点検します。
カバーの3mm厚は今回の接触防止案であり、衝撃/飛散封じ込めの認証値ではありません。

## 5. 有効にする試験範囲と残る3項目

試験目標は**最初150rpm、上限300rpm、停止1秒以内、励磁1秒以内、試行間隔30秒以上、最初の組は5回**です。
正常停止は駆動OFF/PFM無効→初期50ms→パッド作動。惰性側は摩擦作動だけを省き、内蔵ブレーキの解放状態を同じにします。
150rpm域で始動できなければ止め、追加円板付きで高周波の始動キックや上限増加を行いません。
速度・温度・時間は検討用の制約で、実証済みの安全値ではありません。

残る確認は、設計を選び直すための長い未定リストではなく次の3群です。

1. **所有品との接続/保持**: 電力・PFM・Enable・内蔵ブレーキの実入力、低速始動/停止、D軸公差と継手保持、V受けを置ける静止金属面。
2. **加工/組立の受入れ**: 軸受/ハブの実はめあい、軸・円板の振れと遊び、静止押付力1.5N/面、ストローク全域のソレノイド力、解放と非接触、光学検出。
3. **エネルギー/熱**: 未知のモーター慣性を含む0.1J枠、動摩擦・実停止遅延、局所温度・接着・緩み。円板だけの計算を全系の証明にしない。

G0（信号/電源）→G1（モーター単体）→G2（静止ソレノイド/パッド）→G3（カバー内回転体）→G4（同一速度比較）の順序は維持します。
電源断では戻しばねでパッドが離れ、惰性回転が残り得ます。即時停止・フェールセーフ保持ブレーキではありません。
