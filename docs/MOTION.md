# C08: 動き・接触・断面を操作する

**入口は [motion.html](../motion.html)** です。既存の[組立検査台](../index.html)も保持しています。
同じ公開C08の部品・メッシュ・軸変換、ローカルThree.js/OrbitControls、既存の検査関数を使用します。
3軸姿勢制御へ組み込む同軸電磁吸着式摩擦ブレーキの説明であり、車両用/保持用ブレーキや実機安全資格ではありません。

## 開く

リポジトリrootで次を実行し、表示されたURLの末尾に`motion.html`を付けて開きます。

```sh
python3 -B scripts/serve_public.py --port 8767
```

ローカル: `http://127.0.0.1:8767/pico-brake-mechanical-design/motion.html`。
`file://`では3Dデータを読まず、起動方法を示すエラーを表示します。外部CDNや解析通信はありません。
GitHub Pagesの配信先はmainへ反映・デプロイされた後に別途確認してください。作業ブランチへpushしただけでは本番配信済みではありません。

## 操作

| 操作 | 内容 |
|---|---|
| 視点を回転/ズーム | 大きな3D画面をドラッグ、ホイール/ピンチ。部品を回す操作とは別 |
| 動作を再生/一時停止 | ホイール回転、駆動OFF/惰性、電磁石ON、円盤吸着/摩擦停止、解除。初期は停止 |
| 動作の進行 | スライダーを動かすとその時点で停止。回転/接触前/接触/停止/解除後へ直接移動可能 |
| 大きな模式断面 | 接触前後の隙間を拡大した別の模式図。ハブ位置固定、円盤とばね先端だけ追随 |
| 実CADの断面 | 公開nativeから切り出した接触域。名目隙間0.20mm、変位倍率1 |
| 分解/組み戻し | 元の部品台帳の分解ベクトルで表示。分解すると動作をリセット/停止し、復帰しても自動再生しない |
| 場面選択と分解の競合 | 接触等の場面へ移ると組み戻し、選んだ時点で停止。断面への切替でも必要なら組み戻す |
| キーボード | 3Dにフォーカスして矢印キーで視点回転、＋/−でズーム、Homeで視点を戻す。各操作は通常のボタン/スライダー |

初期/動作リセットは、動画の4秒（回転開始直前）の停止状態です。動画内の0〜3秒はXYZの導入です。
視点は再生のたびに回したり戻したりしません。表示モード変更・視点リセット・全体表示・分解時の収まり調整は明示的な操作です。
reduced-motionでも初期自動再生はせず、設定変更/画面非表示では再生を停止します。明示操作による再生は可能です。

## 動画と色

[40秒CG](../media/c08-motion.mp4)と[接触前後の比較](../media/contact-comparison.png)を同梱しています。
HTMLの動画は初期停止・muted=true・volume=0。音声ストリームはありません。
青=回る側、灰=動かない側、橙=電磁石。白い放射状マークは回転に追随する説明用の目印です。
部品名・役割・接触表示も併用し、色だけで判断する必要はありません。

磁力は軸方向に可動円盤を引き、回転を止める摩擦は接線方向です。
摩擦矢印は接触後の減速中だけ表示し、停止後は消します。外力がない停止中に一定の保持トルクが出続けるとは示しません。
コイルOFF後も回転は再開しません。これは説明上の動作で、制御FWの実装/実機検証ではありません。

## 出所・限界

元の[公開範囲](PUBLIC_SCOPE.md)・[権利](../NOTICE.md)を継承します。
ハブは回転だけで軸方向位置を保ち、可動円盤・ばね先端締結が最大0.20mm移動します。
ばねのたわみは根元0/先端追随の描画補間で、弾性解析ではありません。
XYZは公開単軸の剛体複製であり、起立・姿勢保持成功を示しません。

参考ホイール/モーター/筐体の現物適合、motor干渉、電流・磁気・面圧の未達は未解決。
C08はM2/M2.5/M3/M4を含み、全M3化・実機配線・3軸制御・安全資格は今回の範囲外です。
[用途違いの旧卓上R1](../PROTOTYPE.md)は現行C08の採用案から分離して保存しています。

既存READMEは検査済みCAD配布ZIPにも固定収録されるためそのまま保全し、新しい使い方はこの文書にまとめています。
既存入口からこの対話ページへ明示リンクを追加しています。元CAD/STEP/配布ZIPを再生成して差し替える必要はありません。

## データの再生成

実断面は`data/motion-section.json`で、C08公開nativeと元meshのSHAを記録しています。
既存FreeCADのPythonから、リポジトリrootで次を実行します。

```sh
PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib \
 /Applications/FreeCAD.app/Contents/Resources/bin/python -B scripts/build_motion_sections.py
```

元nativeを保存せず、接触部の表示データだけを再生成します。通常の表示にFreeCADやnpmは不要です。

40秒CGの最小再生成一式は[media/source](../media/source/README.md)、
保存済みBlenderは[こちら](../media/source/c08-clear-animation.blend)です。連番画像・作業ログは配布していません。

## 開発検査

```sh
npm test
npm run test:motion
```

隔離したChromeで実カメラ/部品transform、停止、接触前後、実断面/模式断面、分解/組み戻し、mobile、
キーボード、reduced-motion、読込失敗を検査します。検査画像は`test-results/`へ保存し、repoには入れません。
[検査記録](../validation/motion-browser.json)はWeb表示の確認で、実機の安全資格ではありません。
