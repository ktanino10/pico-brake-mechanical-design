## 仕組みと今回の決定

モーターはフレキシブル継手で独立軸を回します。ソレノイドを励磁すると2本のレバーが動き、
固定側の2枚の摩擦パッドで円板を挟みます。回転エネルギーを主に摩擦熱へ変え、
無励磁では戻しばねで離す構成です。Picoは制御信号だけを出し、電力は別経路から供給します。

| 決めたこと | R1の内容 |
|---|---|
| 荷重支持 | 6mm独立軸、626ZZ×2、支持間隔64mm。未知のモーター軸受にブレーキ反力を直接任せない |
| 円板 | SUS304、外径60×厚さ1mm、PCD19のM3用6穴。Pololu1999を独立軸に使用 |
| 継手 | NBK MSTS-25C-6-6、挿入各8.5mm、M3クランプ |
| モーター保持 | 可調整のV受け＋ベルト。既存ねじ孔を使わず、新規締結はM3 |
| ブレーキ | CA08300480、水平対向レバー40:20mm、隙間各0.15mm |
| パッド | 天然ゴムKGR-1100から10×8×1mmを2枚。金属裏板と低温側PLA支持 |
| 戻し | サミニ12-0423、初期取付長16.5mm。電源断で解放する方式 |
| 電装 | Pico H、LVC8T245、Enable用ADA-4409、コイル用ADA-5648、Maker Reflect |
| 信号用5V | モーター分岐12VからAdafruit4739で生成。Pico VBUSは使わない |
| AC入力 | Class II ACA-PD91BK＋付属C-Cケーブル＋DP100。PE必須DPS-3003案は不採用 |
| 試験目標 | 最初150rpm・上限300rpm・停止1秒・励磁1秒以内・試行間隔30秒以上 |

**これらは選んだ設計値で、実測済みの安全値ではありません。**
回転に使うハブや円板を手回し教材の樹脂部品から流用せず、C08のトルク/締付値も転記しません。
既存CAD・画面・README・配布ZIP・教材原本を保持しています。

## 買う/加工する/印刷する

材料表では既存の項目を保ち、R1で選んだ型番・数量へ更新しました。
`設計選定`は今回固定した名目仕様、`購入加工`は加工先へ図面で依頼するものです。
`採用なし`は旧TLP専用端子やモーター取付ねじなど不要になった項目。
`所有済み`のモーター・12極ケーブルは新規購入0、付属ケーブル・付属ねじも二重購入しません。

PLAの機械支持部は**17個のSTLを各1個**。円板、裏板、リンク、小物軸/ブッシュ、
台座、PCカバーは材料と寸法を指定して加工します。製品URLがあることと国内在庫があることは別です。
PololuハブとAdafruit4739の国内向け窓口は海外調達であり、国内即納を約束しません。

価格日付は2026-11-14、送料・加工・予備は別です。
**Pico/電源/アクチュエータ/選定モジュール等の9行の参考小計は20,565円。**
価格のある機械追加4行（ハブパック、継手、軸受2個、ゴムシート）の参考計13,291.3円を合わせても、
**33,856.3円は判明分だけで、全材料費ではありません。**
軸受・ゴムは販売ページの税別標準価格から税込を計算した参考値、ハブも税端数/送料/最終注文額は要確認です。
5V降圧基板、加工、締結、配線保護、工具などの未見積を0円にしません。

CSVはUTF-8。Excelで文字化けする場合は「テキスト/CSVから」でUTF-8を選択します。
`id`はBOM行、`選定条件`は測定ゲート番号で別体系です。使用数と購入パックを区別してください。
ねじ75本の内訳は[接合表](../prototype/mechanical/joints.csv)、副資材を含む必要数量は材料表に記載します。

## 何を確認してから進めるか

申告済み軸寸法は**A=円径6mm、B=有効突き出し15mm、C=D平面から反対曲面4mm、D=D部の軸方向長5mm**です。
同じ4値や追加のコネクタ写真を再度求めることはしません。

残るのは、所有モーターの電力/信号入力と低速応答、継手/V受けの実保持、
加工品のはめあい・振れ・押付力・解放、全回転系のエネルギーと温度です。
モーター回転部慣性は未知のまま別項にし、円板の約21.13g/約0.00495J（300rpm）を装置全体の値にしません。
0.1Jの全系エネルギー枠を超える場合はR1の範囲外です。

順番は**極性/信号→モーター単体→ソレノイド静止→カバー内回転体→同一初期速度の比較**。
駆動を止めてから初期50ms後に摩擦ブレーキを作動し、両条件とも内蔵ブレーキ解放を維持します。
この低速域で始動しなければ、追加円板付きで高周波始動や上限引上げをしません。

**電源断でパッドは解放され得るため、即時停止ではありません。**
モーター/コイル電力をブレッドボードや宙づりクリップに流さず、カバーを閉じたまま完全停止を確認します。
本資料作成では、購入・接続・通電・機器操作はしていません。
